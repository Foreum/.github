# Contributing to Foreum

Thank you for your interest in contributing to Foreum.

Foreum is under active development, so some parts of the project and its workflow may change. Before investing time in a large change, open an issue to discuss the approach.

## Ways to contribute

- Report a reproducible bug.
- Suggest an improvement or feature.
- Improve documentation.
- Submit a focused code change.
- Review an open pull request or help clarify an issue.

## Before opening an issue

1. Search existing issues to avoid duplicates.
2. Use the appropriate issue template.
3. Include relevant context, expected behaviour, and actual behaviour.
4. For bugs, include clear reproduction steps and relevant logs. Remove secrets and personal data.

## Before starting a pull request

- For a substantial change, open or comment on an issue first.
- Keep the change focused; avoid bundling unrelated refactors.
- Follow the conventions already used in the affected part of the codebase.
- Update documentation when behaviour or setup instructions change.
- Add or update tests when appropriate.

## Local development

Use the setup instructions in the main [`Foreum/foreum`](https://github.com/Foreum/foreum) repository. Its README and project configuration are the source of truth for prerequisites, package-manager commands, environment variables, and development scripts.

Do not commit secrets, local environment files, generated credentials, or production data.

## Pull request checklist

Before submitting, check that:

- [ ] The change has a clear purpose and description.
- [ ] Related issues are linked, where applicable.
- [ ] Tests and relevant checks pass, or any limitations are explained.
- [ ] Documentation has been updated where needed.
- [ ] No secrets, credentials, or unrelated generated files are included.
- [ ] The change is focused and ready for review.

## Review process

A maintainer may ask questions, request changes, or close a pull request that is out of scope. Please be patient: Foreum is maintained with limited resources, and response times may vary.

By participating, you agree to follow the project's code of conduct.
